# Banki.shop — тестовое задание

Интернет-магазин «Картины эпохи возрождения» на **Vue 2 (Options API) + TypeScript + Webpack**.

## Требования

- **Node.js 16.x** (рекомендуется через [nvm](https://github.com/nvm-sh/nvm))
- npm 8+

## Быстрый старт

```bash
# 1. Установить зависимости
npm install

# 2. Скачать изображения из макета (логотип, картины, иконки)
npm run setup

# 3. Запустить dev-сервер
npm run serve
```

Приложение откроется на [http://localhost:8080](http://localhost:8080).

## Сборка production

```bash
npm run build
```

Результат сборки — в папке `dist/`.

## Реализованный функционал

### 1. Строка поиска
При вводе текста выполняется фильтрация карточек по названию позиции. Неподходящие карточки скрываются.

### 2. Кнопка «Купить»
Три состояния с иконками:
- **Купить** — иконка корзины
- **Покупка** — спиннер, 2 секунды
- **В корзине** — корзина

### 3. Сохранение состояния
Состояние «В корзине» сохраняется в `localStorage` и восстанавливается после перезагрузки страницы.

### 4. Модальное окно товара
По клику на название или изображение открывается модалка с:
- кратким описанием
- ценой
- слайдером из 2–4 изображений

## Адаптивность

Вёрстка адаптирована для экранов от **360px** до desktop. На мобильных устройствах:
- поиск переносится на отдельную строку
- карточки товаров занимают всю ширину
- модальное окно масштабируется под экран
